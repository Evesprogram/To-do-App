# Week 6 – To-Do App (CRUD + localStorage)

## Objective
Build a to-do app that supports:
- Add task
- Toggle complete
- Delete task
- Filter (All / Active / Completed)
- Persist data using `localStorage`

## Requirements
- Must use `localStorage` to save and reload tasks
- Must use event handling + DOM manipulation
- Must be responsive

## Submission
Push code to GitHub and include a live demo link in this README.
